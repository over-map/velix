# Velix: ride smooth

iPhone bike navigation that picks the best route for how you ride, explains why on the map, and warns about hazards (tram rails, cobbles, lane ends, steps, steep descents). Milan pilot. Open data (OpenStreetMap, Copernicus, GTFS), open-source stack (SwiftUI, MapLibre, Ferrostar, Valhalla). No account; everything stays on your phone.
